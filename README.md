 Sobre o projeto
O Raiz Urbana Connect é uma solução que permite visualizar hortas urbanas em um mapa interativo, facilitando o acesso da população a informações como localização, funcionamento e características.
Funcionalidades
- Visualização de hortas urbanas
- Geolocalização
- Identificação da horta mais próxima
- Interface responsiva (mobile)
 Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- API de geolocalização
 Objetivo
Promover sustentabilidade, inclusão digital e facilitar o acesso à informação pública sobre agricultura urbana.
